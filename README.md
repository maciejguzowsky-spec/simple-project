# Prosty projekt Python

To jest prosty projekt Python z jednym plikiem startowym.

## Uruchomienie

1. Zainstaluj zależności (jeśli są):
```bash
pip install -r requirements.txt
```
2. Uruchom aplikację:
```bash
python main.py
```
